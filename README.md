      <h3>🤖 <a href="https://github.com/sunnysingha911/deskpilot">deskpilot</a></h3>
      <p><b>AI agents that use your computer the way you do, but they ask before anything scary.</b></p>
      <p>Agents drive macOS through the shell, AppleScript, the accessibility tree and the browser DOM. Raw mouse clicks are the last resort. Every action is logged and risk-scored, and anything irreversible (delete, send, purchase) waits for a human 👍.</p>
